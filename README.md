# 🛡️ درع أيمن (Ayman Guard)
**نظام ذكي متطور لفحص الروابط وكشف محاولات التصيد والاحتيال الرقمي.**

## 🚀 المميزات:
- **فحص فوري:** تحليل النطاقات المشبوهة والمنتحلة.
- **بلاغات المجتمع:** نظام تفاعلي للتبليغ عن الروابط الجديدة.
- **المرجع الآمن:** قائمة موثقة للروابط الرسمية (أبشر، نفاذ، البريد).
- **حماية مزدوجة:** تصفية آلية تمنع البلاغات الكاذبة ضد المواقع الرسمية.

**تطوير: أيمن 🦾**
